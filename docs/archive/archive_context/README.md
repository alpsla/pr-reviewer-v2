# Session Context Files

## Purpose
This directory contains key files that should be shared at the beginning of each AI assistant chat session. These files provide essential context about the project's status, architecture, and current tasks.

## Files to Share

### 1. PROJECT_OVERVIEW.md
High-level overview of the project, current status, tech stack, and roadmap.

### 2. ARCHITECTURE.md
Technical architecture of the system, including components, data flow, and design decisions.

### 3. CURRENT_TASKS.md
Active development tasks, recently completed work, and upcoming priorities.

## How to Use

1. Share these files at the beginning of each new chat session:
   ```
   I'd like to continue working on the PR Reviewer project. Here's the current context:
   [Share the three context files]
   ```

2. Update these files at the end of each productive session to reflect:
   - New completed features
   - Changed priorities
   - Architecture modifications
   - Current challenges

## Maintenance Guidelines

1. Keep PROJECT_OVERVIEW.md up-to-date with major milestone completions
2. Update ARCHITECTURE.md when significant architectural decisions are made
3. Refresh CURRENT_TASKS.md at the end of each session
